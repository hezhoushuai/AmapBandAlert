# ESP32 导航显示器（HUD）方案

> 目标：手机继续用高德手机版导航，ESP32 做一个常显的小屏：车速、限速、转向、距离、超速蜂鸣。
> 手环继续负责震动，ESP32 负责“看得见 + 听得见”。

## 先说结论

**有搞头，而且比手环更适合做“常显仪表”**，但它**不能凭空解决手机版高德没有道路限速的问题**。

ESP32 能解决：

- 连续显示 GPS 车速（不用等通知）
- 固定阈值超速 + 大音量蜂鸣（风噪/头盔环境比手环震动更直接）
- 转向箭头、距离、道路名（手机 App 解析高德通知后发过来）
- 不受小米运动健康通知过滤/去重影响
- 可做防水、防震、12V 供电、常亮、物理按键
- 可选独立 GPS，手机断连也能当车速表

ESP32 不能解决：

- 手机版高德不提供“当前道路限速”（高德官方 FAQ：没有摄像头的道路拿不到限速）
- 无法直接读取手机通知/界面；必须由手机 App 桥接
- 不能替代高德的路线规划/语音

所以超速仍然是三条路：

1. 高德车机版广播：真实车速 + 真实限速（最准）
2. GPS + 固定阈值：可靠，但不是道路自适应
3. GPS + 无障碍读高德界面“限速 XX”：实验性

ESP32 只是把这三条路的结果**显示得更好、报警更响**。

## 四个数据到底从哪来

你要的最小数据集是：**路线轨迹、路线上的摄像头、摄像头距离、实时车速**。它们在三种数据源里的可得性完全不同：

| 数据 | 高德手机版 App | 高德车机版广播 | 高德导航 SDK（自己导航） |
|---|---|---|---|
| 已走轨迹 | GPS 自己记 | GPS 自己记 | GPS / SDK 轨迹 |
| 前方规划路线 | 不开放 | 不完整（有转向/剩余，无完整几何） | ✅ `AMapNaviPath` / steps |
| 摄像头类型 | 不开放 | ✅ `CAMERA_TYPE` | ✅ `AMapNaviCameraInfo.getCameraType()` |
| 摄像头限速 | 不开放 | ✅ `CAMERA_SPEED` | ✅ `getCameraSpeed()` |
| 到摄像头距离 | 不开放 | ✅ `CAMERA_DIST` | ✅ `getCameraDistance()` |
| 摄像头坐标 | 不开放 | 通常没有 | ✅ `getX()/getY()` |
| 实时车速 | GPS 可算 | ✅ `CUR_SPEED` | ✅ 当前车速 |
| 当前道路限速 | 不开放 | ✅ `LIMITED_SPEED` | 仅摄像头路段有限速 |

结论：

- **只做“车速 + 摄像头距离 + 超速”仪表**：车机版广播足够，现有 App 已能拿到，接 ESP32 很快。
- **要在地图上画前方完整路线 + 摄像头图标**：需要高德导航 SDK，或者接受“GPS 已走轨迹 + 摄像头距离”这种简化 HUD。
- **手机版高德 App + 完整数据**：没有公开接口；只能 root/Xposed hook，强烈不推荐。

## 推荐架构

```text
高德手机版 / 车机版
        │ 通知 / 广播 / 无障碍
        ▼
AmapBandAlert（手机 App，已有数据引擎）
        │ BLE / Wi-Fi UDP / USB CDC
        ▼
ESP32-S3 + 屏幕 + 蜂鸣器
```

手机 App 仍然是唯一数据源；ESP32 不做解析，只做渲染和报警。这样高德升级时只需要改手机端。

## 三种连接方式

| 方式 | 难度 | 延迟 | 功耗 | 适用 |
|---|---|---|---|---|
| **Wi-Fi UDP** | 最低 | 20–80ms | 高（Wi-Fi 常开） | 第一版原型、车机/摩托车有 12V |
| **BLE GATT** | 中 | 50–200ms | 低 | 量产/电池供电/手机放口袋 |
| **USB CDC** | 低 | <20ms | 低 | 手机固定在支架、能走线 |

建议：

- **原型先用 Wi-Fi UDP**：手机开热点，ESP32 连热点，手机往 ESP32 的 IP:4210 发 JSON。不用配对，一天能跑通。
- **产品化再用 BLE**：ESP32 做 GATT server 广播，手机做 GATT client 写入；断线自动重连。
- **不想折腾无线**：ESP32-S3 原生 USB CDC，手机 USB OTG 直接发串口 JSON，最稳。

## 数据协议

2–5Hz，单行 JSON，UTF-8，建议 < 220 字节：

```json
{"v":1,"seq":123,"spd":72,"lim":60,"src":"gps","limSrc":"fixed","turn":"left","dist":180,"road":"中山路","alert":"overspeed","ts":1730000000}
```

字段：

- `spd`：当前车速 km/h，-1 未知
- `lim`：限速 km/h，-1 未知
- `src`：`gps` / `broadcast` / `notice`
- `limSrc`：`broadcast` / `ui` / `notice` / `fixed`
- `turn`：`left/right/slight_left/slight_right/uturn/roundabout/straight/arrive/unknown`
- `dist`：到转向点距离，米
- `road`：道路名
- `alert`：`overspeed/camera/turn/arrive/none`
- `seq`：递增序号，ESP32 用来判断丢包
- `ts`：手机时间戳

ESP32 侧：

- 3 秒没收到新包 → 显示 `NO LINK`
- `seq` 回退/重复 → 丢弃
- 收到 `alert=overspeed` → 蜂鸣 + 红屏/闪烁
- 车速字号最大，限速牌次之，转向箭头居中

## 硬件建议

### 方案 A：一体开发板（最快）

- **Waveshare ESP32-S3-Touch-LCD-1.28**：圆形 240×240 IPS、触摸、锂电池管理、S3
- 或 **LilyGO T-Display-S3**：1.9" 170×320，便宜、资料多
- 优点：不用自己画屏、接线少；缺点：亮度/防水要自己做

### 方案 B：散件（适合做壳）

- MCU：ESP32-S3-Zero / ESP32-S3-DevKitC-1（带 PSRAM 更好）
- 屏：1.28" GC9A1D 240×240 圆屏，或 2.0" ST7789 320×240 IPS
- 供电：12V→5V 3A buck（MP1584/XL4015），保险丝、TVS
- 蜂鸣器：有源 85–95dB + 三极管
- 可选：ATGM336H GPS、BH1750 光感、SD 卡、物理按键
- 外壳：IP65 ABS/3D 打印，遮光罩，RAM 支架

### 选购注意

- **阳光下可读性**是最大坑：优先 500nits 以上 IPS，加防眩光膜/遮光罩；不要用电子墨水屏做车速（刷新太慢）。
- 摩托车/骑行：12V 取电要保险丝、防反接、防震；USB-C 供电只适合车内有线。
- 蜂鸣器在风噪下可能听不见；可以先做“屏幕闪烁 + 蜂鸣”，后续再考虑头盔骨传导/震动马达。
- 不要装在遮挡视线的位置；行驶中不要触摸操作。

## 软件栈

- 固件：PlatformIO + Arduino 或 ESP-IDF；LovyanGFX/TFT_eSPI + LVGL
- BLE：NimBLE（GATT server，手机写入，ESP32 notify ACK）
- Wi-Fi：UDP 监听 4210；手机广播发现或固定 IP
- USB：ESP32-S3 USB CDC，115200–921600
- 设置存 NVS：亮度、蜂鸣开关、单位、超速阈值
- 看门狗、断线重连、低电量休眠、OTA

## 手机 App 需要改什么

现有 `AlertEngine` 已经有车速/限速/转向状态，只需加一个出口：

- `Esp32Link` 接口：`start/stop/send(Snapshot)`
- 三种实现：`UdpEsp32Link`、`BleEsp32Link`、`UsbEsp32Link`
- 前台服务加 `connectedDevice` 类型（BLE/USB）或 `INTERNET`（UDP）
- BLE 权限：Android 12+ `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT`
- UI：ESP32 连接状态、设备名、测试按钮
- 发送频率：导航中 5Hz，怠速 1Hz；只发变化 + 心跳

## 里程碑

1. **M1（1–2 天）**：手机 UDP 发假数据，ESP32 屏幕显示车速/限速，蜂鸣器响
2. **M2（2–3 天）**：接真实 GPS/固定阈值，手机 App 发真实数据
3. **M3（3–5 天）**：转向箭头/道路名、断线提示、亮度自适应
4. **M4**：BLE 版、外壳、防水、12V 供电、路测
5. **M5**：可选独立 GPS、SD 日志、OTA

## 成本估算

- 一体屏开发板：¥80–150
- 散件：¥120–220
- 外壳/支架/线材：¥50–100
- 合计：**¥200–350**（不含手机）

## 风险

- 手机版高德限速数据缺失（方案层面无解，只能车机版/无障碍/固定阈值）
- 阳光可读性、防水、震动、供电
- BLE 配对/重连在部分 ROM 上不稳定
- 手机发热/耗电（Wi-Fi 比 BLE 明显）
- 法规/安全：不要遮挡视线，不要行驶中操作

## 建议的第一版

**ESP32-S3 1.28" 圆屏 + Wi-Fi UDP + 手机热点 + 蜂鸣器**，只做：

- 大字号车速
- 限速/固定阈值
- 超速红屏 + 蜂鸣
- `NO LINK` 提示

跑通后再加转向箭头/BLE/外壳。这样一周内能看到实物效果，也不会一上来被 BLE 配对和防水拖住。
