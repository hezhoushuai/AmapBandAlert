# AmapBandAlert

高德地图导航时，限速拍照电子眼预警 → 小米手环 9 Pro 震动提醒。

适用于驾车、骑行、摩托等任何使用高德导航的场景——开车时手机静音在扶手箱、
骑行时风噪大听不到语音、任何"听不到播报但需要知道前方测速"的场景。

## 原理

高德地图 App 导航时通过系统广播 `AUTONAVI_STANDARD_BROADCAST_SEND` 持续推送导航数据
（转向/车速/限速/电子眼距离等，AmapAuto 标准广播协议）。
本 App 监听该广播，在电子眼进入预警距离时触发高优先级通知，
经小米运动健康转发到手环产生震动。

- 不依赖无障碍服务，不修改高德，不上传任何数据
- 不需要高德开放平台 Key
- 高德照常使用，体验无任何改变

## 构成

| 部分 | 技术 | 功能 |
|---|---|---|
| `android-app/` | Android (Java) | 广播监听 + 预警引擎 + 通知触发 |
| `wearable/` | Vela 快应用 (JS) | 手环端限速预警页 + 三段强震 (P1) |

## 使用

1. 安装 APK，授予通知权限
2. 点"启动监听服务"
3. 点"发送测试通知" → 手环应震动（需小米运动健康开启应用通知转发）
4. 高德开始导航，经过限速拍照点 → 手环震动

## 手环支持

- 小米手环 9 Pro（通知转发，P0；专属快应用，P1）
- 理论上任何支持"应用通知转发+震动"的穿戴设备都可用（华为/Amazfit 等未验证）
